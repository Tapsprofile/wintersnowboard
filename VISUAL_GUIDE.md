## Interactive Elements

### Menu Toggle Behavior
```
[☰ Menu] (Click) → Navigation slides down
                  → Icon changes to [✖]
                  → Button color changes red

[✖ Menu] (Click) → Navigation slides up
                  → Icon changes to [☰]
                  → Button color returns blue
```

### AJAX Add to Cart Flow
```
[Add to Cart] (Click) → Button shows "Adding..."
                       → AJAX request to server
                       → Cart count updates (2 → 3)
                       → Cart icon pulses
                       → Button shows "Added!" (green)
                       → After 2s returns to normal
```

### Search Field Interaction
```
[Search Field] (Focus)  → Border highlights blue
                        → Box shadow appears
                        → Slight scale increase

[Search Field] (Type)   → Real-time search (if enabled)
                        → Placeholder disappears

[Search Field] (Submit) → Redirects to search results
                        → Shows product matches
```

### Review Section
```
Initial State: Shows 5 reviews
[Show More Reviews] (Click) → Slides down 5 more reviews
                            → Button text changes to "Show Less"

[Show Less Reviews] (Click) → Slides up extra reviews
                            → Scrolls to review section top
                            → Button text back to "Show More"
```

## Animation Types

1. **Flash Effect** (Top Bar)
   - Opacity pulse: 1.0 → 0.8 → 1.0
   - Duration: 2s infinite

2. **Slide Effect** (Top Bar)
   - Highlight slides left to right
   - Duration: 3s infinite

3. **Gradient Shift** (Top Bar)
   - Background position animates
   - Duration: 5s infinite

4. **Menu Slide** (Navigation)
   - Max-height: 0 → 500px
   - Duration: 0.3s ease

5. **Product Hover** (Cards)
   - Transform: translateY(-10px)
   - Box-shadow increases
   - Duration: 0.3s ease

6. **Button Ripple** (Add to Cart)
   - Radial expansion on hover
   - Duration: 0.6s

7. **Cart Pulse** (Icon Update)
   - Scale: 1.0 → 1.1 → 1.0
   - Duration: 0.5s
